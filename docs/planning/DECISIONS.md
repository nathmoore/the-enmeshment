| 2026-06-12 | **Paste-prompt / "Field Kit" mode cut — single-mode game (adaptive interview only).** Removes the two-mode design (Mode A: run a self-profiling prompt in your own AI tool, paste the result back; Mode B: in-game interview). The game is now *only* the oblique in-game interview. Deletes `src/prompts/profile-prompt.md`; drops the Field Kit Epic 1 deliverable and the "combine Mode A+B" question | The paste-prompt was the one mechanic that actively invited players to *extract* data from other AI tools and paste it back — exactly the oversharing risk that is the game's single biggest real-world hazard (MECHANICS §III, risk-2). Reframes the Epic 1 "question bank" into an **elicitation playbook** (question *types* + interview techniques + the signal each reveals) + a few reliable **anchor questions** (incl. the politeness meme) + the confidence-threshold stop rule | Follows from the intake-agent reframe (below) and the finding that free-form, persona-driven inference beats form-filling (MECHANICS §I, §F); keeps the game fun, replayable, genuinely conversational. **Two consequences raise *existing* risks:** (1) guardrails must now bound questions generated on the fly — "what it must never ask" becomes load-bearing and the oversharing risk (MECHANICS §III, risk-2) grows; (2) classification consistency must be protected via anchor questions + signal→archetype rules so divergent paths still converge.
